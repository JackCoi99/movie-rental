Documentación de la API

La API usa FastAPI y una base de datos relacional para gestionar el catálogo y los alquileres.

Modelo de datos
Entidades Relación Clave o tabla de enlace
Director → PelículaUno a muchosmovies.director_id
Película ↔ ActorMuchos a muchosmovie_actor
Película ↔ GéneroMuchos a muchosmovie_genre
Película → AlquilerUno a muchosrentals.movie_id
Usuario → AlquilerUno a muchosrentals.user_id
Endpoints y respuestas

GET / devuelve el estado de la API. Las operaciones siguientes se aplican a /movies, /directors, /actors, /genres, /users y /rentals.

Petición Entrada Salida
GET /{recurso}Sin parámetros200 · lista JSON
GET /{recurso}/{record_id}ID positivo200 · objeto JSON
POST /{recurso}Cuerpo JSON201 · objeto creado
PUT /{recurso}/{record_id}ID y cuerpo completo200 · objeto actualizado
DELETE /{recurso}/{record_id}ID positivo204 · sin cuerpo

404 indica un registro o referencia ausente, 409 un conflicto y 422 datos inválidos.

Campos de entrada y salida

Las respuestas incluyen el ID y los datos de la entidad. Películas y alquileres también incluyen sus relaciones anidadas.

Recurso Campos obligatorios Campos opcionales
Películasname, year, director_iddescription, available, actor_ids, genre_ids
Directoresname, surnameyear, country, bio
Actoresname, surnameyear, country
Génerostype—

Ejemplos de peticiones JSON

Usa identificadores existentes para las relaciones. En PUT, incluye todas las asociaciones que quieras conservar. Una lista vacía elimina sus vínculos.

{
  "name": "La última marea",
  "year": 2019,
  "director_id": 1,
  "actor_ids": [2],
  "genre_ids": [3],
  "description": null,
  "available": true
}
