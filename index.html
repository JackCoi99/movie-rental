Documentación de la API

Consultar Swagger ↗

Movie Rental API organiza un catálogo de cine y registra préstamos de películas a usuarios. El backend usa FastAPI y una base de datos relacional.

Modelo de datos

EntidadesRelaciónClave o tabla de enlace
Director → PelículaUno a muchosmovies.director_id
Película ↔ ActorMuchos a muchosmovie_actor
Película ↔ GéneroMuchos a muchosmovie_genre
Película → AlquilerUno a muchosrentals.movie_id
Usuario → AlquilerUno a muchosrentals.user_id

Endpoints

GET / devuelve el estado de la API. Las operaciones siguientes se aplican a /movies, /directors, /actors, /genres, /users y /rentals.

PeticiónEntradaSalida
GET /{recurso}Sin parámetros200 · lista JSON
GET /{recurso}/{record_id}ID entero positivo200 · objeto JSON
POST /{recurso}Cuerpo JSON201 · objeto creado
PUT /{recurso}/{record_id}ID y cuerpo completo200 · objeto actualizado
DELETE /{recurso}/{record_id}ID entero positivo204 · sin cuerpo

404 indica que falta un registro o una referencia, 409 indica un conflicto de integridad y 422 indica datos inválidos.

Ejemplos JSON

Usa identificadores existentes. En PUT, incluye todas las asociaciones que quieras conservar. Las listas vacías eliminan sus vínculos.

POST /movies

{
  "name": "La última marea",
  "year": 2019,
  "director_id": 1,
  "actor_ids": [2],
  "genre_ids": [3],
  "description": null,
  "available": true
}
